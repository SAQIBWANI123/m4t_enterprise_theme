Home menu

Search from the first keystroke

The home menu listens as soon as you type. Your text opens the command palette with results for apps, menus and records, and a footer reminds you that Ctrl/⌘ + K opens it from anywhere.

Navigation

A navbar that gets out of the way

A white navbar with a clean grid toggle. Inside an app it shows the app name and menus; on the home menu everything else hides. Open the grid over a running app and it becomes a back arrow to your previous view.

Forms & lists

Notebook tabs with a brand accent

Inactive tabs sit on a soft grey, the active tab gets a purple top bar. Buttons are flat, inputs are minimal and lists are quietly divided, just like Enterprise.

Setup

Installation & configuration

Install

  1. Copy m4t_enterprise_theme to your addons path.
  2. Restart the Odoo server.
  3. Enable developer mode, open Apps → Update Apps List.
  4. Search “M4T Enterprise Theme” and click Install.
  5. Reload the browser. The theme is active immediately.

Set a background

  1. Go to Settings → General Settings.
  2. Scroll to Home Menu Background.
  3. Click the image box and choose a picture (1920×1080 recommended).
  4. Click Save and reload. Remove the image to restore the default.
Good to know: the theme targets Odoo 19 Community. Uninstalling it restores the standard interface. Backgrounds are stored per company.
